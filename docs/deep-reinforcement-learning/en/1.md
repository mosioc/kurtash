# Complete Summary of Chapter 1 of *Deep Reinforcement Learning*

Chapter 1 focuses primarily on understanding Deep Reinforcement Learning (DRL), the foundations of Reinforcement Learning, the history of artificial intelligence, the architecture of neural networks, and the challenges of reinforcement learning.

## Part 1: Basic Concepts of Artificial Intelligence and Reinforcement Learning

## 1. Artificial Intelligence (AI)

**Artificial intelligence** is a branch of computer science whose goal is to build systems that can simulate certain human cognitive capabilities, including:

- Learning: learning from data and experience
- Reasoning: reasoning
- Problem Solving: problem solving
- Planning: planning
- Decision Making: decision making
- Perception: perceiving the environment

Examples:

- Search engines
- GPS systems
- Intelligent assistants
- Image recognition
- Robotics

Important note: AI does not necessarily mean building a machine with human-like intelligence or consciousness. Its main focus can be solving problems and performing intelligent tasks.

## 2. Machine Learning (ML)

**Machine learning** is a subfield of artificial intelligence in which a system learns patterns from data and experience instead of having all rules defined manually.

Three main approaches to machine learning:

| Type | Concept |
| ---------------------- | ------------------------------------ |
| Supervised Learning | Learning from labeled data |
| Unsupervised Learning | Discovering patterns in unlabeled data |
| Reinforcement Learning | Learning through interaction and reward |

## 3. Deep Learning (DL)

**Deep learning** is a subfield of machine learning that uses multi-layer neural networks to learn complex relationships and patterns.

Important applications:

- Image processing
- Natural language processing
- Speech recognition
- Feature extraction from complex data

Important distinction:

- Machine learning is a broad field of learning methods.
- Deep learning uses deep neural networks for learning.
- Reinforcement learning is a learning method based on interaction and reward.

## 4. Reinforcement Learning (RL)

The foundational concept of the chapter

Reinforcement learning is a machine learning method in which a system learns how to achieve its goals by interacting with an environment, taking various actions, and receiving feedback.

Core idea:

**Learning through trial and error**

Suppose a robot is supposed to learn to walk:

1. It performs a movement.
2. It observes the result of the movement.
3. It receives a reward for a desirable result.
4. It receives a smaller reward or a penalty for an undesirable result.
5. It changes its behavior based on previous experiences.

Main goal of RL:

```math
\max \mathbb{E}\left[\sum_{t=0}^{T} \gamma^t r_{t+1}\right]
```

That is, maximizing the expected sum of (discounted) rewards over time.

Important note: The goal is not merely to receive the highest immediate reward; the system must also consider the long-term consequences of its decisions.

## 5. Deep Reinforcement Learning (DRL)

Deep reinforcement learning combines two concepts:

- Reinforcement Learning
- Deep Learning

In this approach, deep neural networks are used to solve complex reinforcement learning problems.

**Conceptual structure of DRL**

**Deep Learning**

Processing complex data and approximating relationships

**Reinforcement Learning**

Learning from interaction, actions, and rewards

**Deep Reinforcement Learning**

Learning complex decision-making with the help of deep neural networks

Example: An intelligent agent playing a video game receives images of the game, analyzes the game state, selects the next move, and learns based on its outcome.

Important note on the relationship between these concepts:

```math
\text{DRL} \subset \text{RL} \subset \text{ML} \subset \text{AI}
```

Of course, DL is also a subset of ML and has a combined relationship with RL; therefore, DRL is the product of combining DL and RL, not that RL is a subset of DRL.

## 6. Sequential Decision Making

**Sequential decision making** means the system must make a series of decisions over time,decisions that affect future states and subsequent decisions.

Examples:

- In chess, every move affects the next position.
- In robotics, every arm movement changes the state for the next movement.
- In autonomous driving, every decision affects future driving conditions.

This concept is one of the most important reasons for using RL.

## 7. Uncertainty

**Uncertainty** means the system cannot predict with complete confidence the outcome of its actions or the future state of the environment.

Example:

A robotic arm wants to pick up an object; however:

- The object may have moved.
- The object's weight may differ.
- Sensors may be noisy.
- Motor movement may be imprecise.

Therefore, DRL is suitable for sequential decision-making problems under uncertainty.

## Part 2: Core Components of Reinforcement Learning

This part is one of the most important sections of the chapter, since almost all RL algorithms are built on these concepts.

## 9. Agent

The **agent** is the decision-making component of the system.

Agent responsibilities:

- Receiving information from the environment
- Selecting an action
- Learning from the outcomes of actions
- Improving decision-making over time

Example: In a robot, the software that decides which direction the robot arm should move is the agent.

Important note: The agent is not necessarily the robot itself or its hardware; it is the decision-making component.

## 10. Environment

The **environment** is everything outside the agent's direct control with which the agent interacts.

For example, in a robot:

- Object positions
- Ground surface
- Environmental conditions
- Camera noise
- Network latency
- Motor errors

The agent makes decisions, but it does not control everything that happens in the environment.

## 11. State

The **state** is a complete representation of the information relevant to the current condition of the environment.

Example in a robotic arm:

- Current arm position
- Movement velocity
- Object position
- Joint states
- Information related to environmental conditions

The state encompasses all information relevant to defining the problem's condition.

## 12. State Space

The **state space** is the set of all possible states the environment can be in.

For example, if the position and velocity of an arm can vary, all possible combinations of these variables form the state space.

```math
\mathcal{S} = \{s_1, s_2, s_3, \ldots\}
```

Each `s` is a specific state.

## 13. Observation

An **observation** is the information the agent directly receives from the environment.

Important difference between state and observation:

| State | Observation |
| -------------------------------- | -------------------------------- |
| Complete state of the environment | Information observable to the agent |
| May include hidden information | May be partial or noisy |
| Describes the true system state | Representation of received information |

Example:

A robot may only see an image of an object through a camera but may not have access to its exact weight, 3D position, or velocity.

In this situation:

- State: complete information about the situation
- Observation: the image received from the camera

Sometimes in simple problems these two terms are used interchangeably, but conceptually they are different.

## 14. Action

An **action** is a decision or movement the agent selects to influence the environment.

Examples:

- Moving left or right
- Increasing speed
- Moving a robot arm
- Selecting a move in a game

The set of all possible actions is called the action space.

## 15. Action Space

The **action space** is the set of all actions the agent can choose from.

Two general types:

- Discrete action space: limited and discrete actions, such as up, down, left, and right.
- Continuous action space: continuous actions, such as setting a motor's angle or speed within a numeric range.

## 16. Reward

A **reward** is a numeric signal indicating how desirable the outcome of an interaction was.

Examples:

- Reaching the goal: positive reward
- Colliding with an obstacle: negative reward
- Moving toward the goal: small positive reward

The agent's goal is to learn behavior that maximizes the expected sum of rewards.

## 17. Reward Function

The reward function specifies how much reward the agent receives in different states and conditions.

```math
R(s, a, s')
```

In this notation, the reward depends on the current state, the action, and the next state.

Very important note: Designing the reward function is one of the most sensitive parts of RL. If the reward function is not aligned with the true objective of the problem, the agent may learn behavior that scores well numerically but is undesirable in practice.

## 18. Transition Function

The transition function specifies how the next state is determined when an action is taken in the current state.

```math
P(s' \mid s, a)
```

This function describes the probability of transitioning from the current state `s` to the next state `s'` as a result of the selected action `a`.

Example:

A robot is in a specific position and decides to move left. The transition function describes the probable state after this movement.

## 19. Model of the Environment

The environment model is a description of the environment's behavior that can include:

- Transition model: predicting the next state
- Reward model: predicting the reward

Using the environment model, predictions can be made about the consequences of possible actions.

## Part 3: The Learning Cycle and How the Agent Works

## 20. Reinforcement Learning Cycle

Reinforcement learning is an iterative process in which the agent and the environment interact.

**1. Agent observes the environment**

Receives observation

**2. Agent selects an action**

Selects an action based on the current policy

**3. Environment responds**

Changes state and produces reward

**4. Agent learns from feedback**

Evaluates the outcome and improves decision-making

The cycle repeats at the next time step

This cycle is the basis of reinforcement learning.

## 21. Time Step

Each stage of interaction between the agent and the environment is a time step.

At each time step, typically:

1. The agent receives information from the environment.
2. It selects an action.
3. The environment responds to the action.
4. The reward and the new state are determined.

## 22. Experience

Each interaction between the agent and the environment produces an **experience**.

Common representation of an experience:

```math
(s_t, a_t, r_{t+1}, s_{t+1})
```

where:

| Symbol | Concept |
| -------------- | ---------------- |
| `s_t` | Current state |
| `a_t` | Selected action |
| `r_{t+1}` | Received reward |
| `s_{t+1}` | Next state |

The agent uses these experiences to improve its behavior.

## 23. Episodic Tasks

**Episodic tasks** are tasks with a defined beginning and end.

Examples:

- Playing a game until it ends
- Completing a level of a game
- Moving a robot until it reaches a destination

Each complete execution of the task is an episode.

An episode consists of a sequence of time steps.

```math
\text{Episode} = (s_0, a_0, r_1, \ldots, s_T)
```

## 24. Continuing Tasks

**Continuing tasks** are tasks that have no natural, defined end.

Examples:

- Continuously controlling a system's temperature
- Continuous movement of a robot
- Continuous management of energy consumption

Main difference:

| Episodic | Continuing |
| ----------------- | ----------------------- |
| Defined beginning and end | No natural end |
| Has episodes | Continuous stream of interaction |
| Example: a match | Example: continuous system control |

## 25. Sequential Feedback

In RL, feedback is received sequentially over time.

The problem is that the outcome of an action may not be immediately apparent.

For example, in chess, a move may lead to victory several moves later.

This is one of the most important challenges in RL.

## 26. Delayed Rewards

A **delayed reward** occurs when the agent must take several actions before receiving a reward.

Example:

A robot must navigate through a maze. It receives a reward at the end of the path but may receive no reward along the way.

The problem is that the agent must figure out which earlier actions contributed to the final reward.

## 27. Temporal Credit Assignment Problem

A very important concept

The temporal credit assignment problem is the challenge of determining which actions over time led to a positive or negative outcome.

Example:

A robot takes several movements and eventually reaches the goal.

Which movements actually contributed to the success?

Conversely, if the robot fails, which action was responsible for the failure?

This problem is especially difficult under the following conditions:

- Rewards are delayed.
- The number of actions is large.
- The outcome of an action depends on subsequent actions.
- Environmental factors also influence the outcome.

Note: The agent must learn the relationship between sets of actions and the final outcome, rather than focusing solely on immediate reward.

## Part 4: Methods of Agent Learning

## 28. Policy

A **policy** is the agent's decision-making strategy.

The policy specifies which action the agent should select in a given state or given observed information.

```math
\pi(a \mid s)
```

This notation shows the probability of selecting action `a` in state `s`.

In plain terms:

Policy = how the agent makes decisions

Example:

If the robot sees an obstacle on the right, the policy may tell it to move left.

## 29. Value Function

A value function estimates how valuable a state or action is in the long run.

In other words, a value function helps the agent understand which state or action can yield more reward in the future.

Two important concepts:

- State value: the value of a state
- Action value: the value of taking an action in a specific state

Common mathematical notation:

```math
V^\pi(s) = \mathbb{E}_\pi\left[\sum_{k=0}^{\infty} \gamma^k r_{t+k+1} \,\middle|\, s_t = s\right]
```

The expected value of being in state `s` under a given policy.

And:

```math
Q^\pi(s, a) = \mathbb{E}_\pi\left[\sum_{k=0}^{\infty} \gamma^k r_{t+k+1} \,\middle|\, s_t = s, a_t = a\right]
```

The expected value of selecting action `a` in state `s` under a given policy.

## 30. Environment Model

An environment model attempts to predict the future behavior of the environment.

For example:

- If the agent moves left, what happens?
- What new state is created?
- What reward will be received?

This model can help the agent in planning and selecting better actions.

## 31. Actor-Critic Architecture

The Actor-Critic architecture consists of two main components:

**Actor**

# Policy

Selecting actions and determining behavior

**Critic**

# Value Function

Evaluating the quality of a state or action

The critic helps improve the actor's decision-making.

- The actor is responsible for selecting actions.
- The critic is responsible for evaluating the quality of decisions.

This architecture attempts to leverage the combination of decision-making and evaluation for more effective learning.

## 32. Artificial Neural Networks (ANN)

An artificial neural network is a computational structure composed of a set of processing units and mathematical functions.

A neural network is simply composed of three types of layers:

1. Input layer: receives input
2. Hidden layers: process and transform information
3. Output layer: produces output

Each layer receives the previous layer's output and processes it using mathematical transformations.

Deep networks with multiple layers can learn more complex relationships.

Note: A neural network is a computational structure, not a reinforcement learning algorithm by itself.

## 33. Deep Neural Networks

Deep neural networks are neural networks with multiple processing layers.

Their use in DRL:

- Processing complex inputs
- Feature extraction
- Policy approximation
- Value function approximation
- Learning complex relationships among state, action, and reward

Important example: In video games, a neural network can extract the features needed for decision-making from raw game images.

## 34. Function Approximation

In complex problems, storing or separately computing the value of every state and action is impractical.

For this reason, function approximation is used.

That is, instead of computing all values exactly, a function is used to estimate them.

Deep neural networks are one of the key tools for this.

## 35. Overfitting

Overfitting occurs when a model learns the training data or experiences too well but does not perform well in new situations.

Example:

The agent performs very well in a training environment, but when the environment changes slightly, it cannot maintain its performance.

Remedies mentioned in the chapter:

- Regularization
- Using more samples
- Paying attention to generalization

## 36. Generalization

Generalization is the ability of a model to perform well under conditions and on data it has not previously encountered.

A good agent should not learn only the training scenarios; it should be able to generalize its learning to new conditions.

## Part 5: Fundamental Challenges of Reinforcement Learning

## 37. Evaluative Feedback

Evaluative feedback only tells the agent whether its performance was good or bad.

However, it does not necessarily explain why a decision was good or bad.

Example:

In a game, the agent realizes it won, but from the outcome of the win alone it cannot determine exactly which move led to success.

This makes it necessary for the agent to experiment and gain experience.

## 38. Exploration

**Exploration** means the agent tries new actions to gain more information about the environment and the consequences of actions.

Example:

A robot tries new paths to find a better route.

## 39. Exploitation

**Exploitation** means the agent uses its prior knowledge and experiences and selects actions it knows are likely to yield good rewards.

Example:

If the robot has already found a path that reaches the goal, it uses that same path again.

## 40. Exploration vs. Exploitation Trade-off

A key concept in RL

One of the most important issues in reinforcement learning is balancing exploration and exploitation.

| Exploration | Exploitation |
| -------------------------- | -------------------------------- |
| Trying new options | Using prior knowledge |
| Gaining more information | Using existing information |
| Possibility of discovering a better way | Receiving rewards based on experience |
| Higher probability of failure | Risk of missing new opportunities |

If the agent always explores, it may never make good use of its prior knowledge.

If it always exploits, it may never find a better solution.

The goal is to find the right balance between the two.

## 41. Sample Feedback

In real problems, the agent does not have access to all possible information.

Instead, it receives only samples of experience and feedback.

Therefore, it must learn the general behavior of the environment from its limited experiences.

This makes learning harder, because the agent must estimate complex relationships from incomplete information.

## 42. Sample Efficiency

**Sample efficiency** refers to how much experience or how many samples an algorithm needs to reach desirable performance.

In DRL, one important problem is that the agent may need millions of interaction samples to learn a complex task.

By comparison, humans typically learn certain skills with far fewer experiences.

Influencing factors:

- Complexity of the environment
- Number of possible states
- Number of possible actions
- Difficulty of predicting outcomes
- Quality of the learning algorithm

## 43. Transfer Learning

**Transfer learning** means using knowledge gained from one task to learn another task.

Example:

A robot that has already learned how to pick up a hammer can use its prior knowledge to learn how to pick up a screwdriver.

Benefits:

- Reducing the need to train from scratch
- Saving time
- Reducing learning costs
- Reusing prior knowledge

## 44. Hierarchical Reinforcement Learning

Hierarchical reinforcement learning attempts to decompose complex behavior into a set of smaller tasks or skills.

For example, for a robot to reach a destination:

1. Moving
2. Detecting obstacles
3. Navigating around obstacles
4. Finding a path
5. Reaching the destination

This approach can help organize decisions and reuse learned skills.

## 50. Inverse Reinforcement Learning (IRL)

Inverse reinforcement learning is a method in which a system attempts to infer the hidden objective or reward function of an expert agent from that agent's behavior.

Important difference:

| RL | IRL |
| -------------------------------- | --------------------------------------------- |
| Learning behavior through reward | Inferring reward from expert behavior |
| Reward is known | The intended reward must be estimated |
| The agent learns appropriate behavior | The agent first extracts the expert's behavioral objective |

Chapter example: Autonomous helicopters that use the behavior and control of expert pilots for learning.

## 51. Policy Gradient Methods

Policy gradient methods are a family of RL algorithms that directly optimize the parameters of a policy to improve its performance.

Core idea:

Instead of only estimating the value of actions, the policy is directly changed to increase the probability of selecting desirable actions.

A common form of the policy gradient update:

```math
\nabla_\theta J(\theta) = \mathbb{E}_\pi\left[\nabla_\theta \log \pi_\theta(a \mid s) \, Q^\pi(s, a)\right]
```

The chapter mentions the use of these methods to train a soccer robot and increase its movement speed.

## 52. Deep Q-Network (DQN)

One of the most important historical milestones in DRL

**DQN**

An algorithm that uses a deep neural network to estimate the value of actions.

DQN, introduced in DeepMind research, particularly the work of Volodymyr Mnih and colleagues in 2013 and 2015, was an important milestone in DRL.

Key features:

- Learning from raw images of Atari games
- Using CNNs to extract features from images
- Estimating action values
- Learning without the need to manually define visual game features
- Ability to learn from a set of different games with a shared architecture

The DQN loss is typically expressed as:

```math
L(\theta) = \mathbb{E}\left[\left(r_{t+1} + \gamma \max_{a'} Q(s_{t+1}, a'; \theta^-) - Q(s_t, a_t; \theta)\right)^2\right]
```

where `\theta^-` denotes the parameters of the target network.

### What is a CNN?

A Convolutional Neural Network is a type of neural network particularly suited to processing spatially structured data such as images.

In DQN, a CNN can extract features such as the positions of the player, ball, and obstacles from the game image.

Important note: DQN enabled the agent to learn from raw visual input, rather than having all game information pre-provided as simple, hand-crafted features.

## 53. The Game of Go and State-Space Complexity

This problem illustrates why traditional search methods are limited for problems with very large state spaces and why deep learning methods can be useful.

## Part 9: Learning Structure and the Book's Algorithms

## 69. Tabular Reinforcement Learning

Tabular reinforcement learning is a method in which information about states and actions is stored in a table.

Example:

A robot moves in a Grid World-like environment. If the number of states and actions is limited, information about them can be maintained in a table.

Features:

- Suitable for small problems
- Allows examining different states and actions
- Simpler understanding of basic RL concepts
- Limited in very complex and large environments

## 70. Value-Based Methods

Value-based methods attempt to learn the value of states or actions.

The goal is for the agent to be able to determine which action in a given state is more valuable in the long run.

Examples: Q-Learning and DQN.

## 71. Policy-Based Methods

Policy-based methods directly learn the agent's decision-making policy.

Instead of first estimating the value of all actions, they optimize the parameters of the policy.

Example: Policy Gradient.

## 72. Actor-Critic Methods

These methods combine the value-based and policy-based approaches.

- Actor: action selection
- Critic: decision evaluation

### Relationships among the most important concepts

**General structure of an RL problem:**

1. **Environment**
   - Has `State` and `State Space`.
   - Provides the current state to the agent via `Observation`.

2. **Agent**
   - Makes decisions using a `Policy`.
   - Selects an `Action`.

3. **Environment**
   - Receives the action.
   - Causes the `State` to change.
   - Produces a `Reward`.

4. **Experience**
   - The result of the agent's interaction with the environment.
   - Includes state, action, reward, and next state.

5. **Learning**
   - The agent learns from experiences.
   - With the goal of improving the `Policy` and `Value Function`.

6. **Repetition of the cycle**
   - This process repeats for subsequent time steps.

## A Few Notes for Scientific Accuracy

Keep the following in mind while studying:

- RL and DL are both subfields of ML; DRL arises from their combination.
- Reward does not necessarily reflect the true quality of a behavior; it is only a signal defined by the system designer.
- State and observation are not always the same.
- Maximizing immediate reward differs from maximizing long-term cumulative reward.
- A neural network is not an RL algorithm in itself; it is a tool for approximating the functions the agent needs.
- Success in a training environment does not necessarily mean success in a real environment.
