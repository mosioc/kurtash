# Comprehensive Summary of Chapter 12 of Grokking Deep Reinforcement Learning

**Chapter 12: Advanced Actor-Critic Methods**

This chapter of **Grokking Deep Reinforcement Learning** by Miguel Morales covers four important and advanced deep reinforcement learning algorithms:

1. DDPG (Deep Deterministic Policy Gradient)
2. TD3 (Twin Delayed Deep Deterministic Policy Gradient)
3. SAC (Soft Actor-Critic)
4. PPO (Proximal Policy Optimization)

The main goal of the chapter is to become familiar with methods that can perform more stably in complex environments, especially environments with continuous action spaces.

## 1. Introduction: Advanced Actor-Critic Methods

### 1.1. Why Do We Need Advanced Actor-Critic Algorithms?

In chapter 11, we became familiar with policy gradient and actor-critic methods.

In policy gradient methods, the agent directly learns the policy to increase the expected sum of rewards.

But directly learning the policy can come with problems:

- **High variance:** large fluctuations in the policy gradient estimate.
- **Training instability:** instability in the training process.
- **Poor exploration:** insufficient exploration of the environment.
- **Large policy updates:** excessive changes to the policy that can ruin the agent's performance.
- **Continuous action complexity:** the difficulty of selecting actions in environments with continuous action spaces.

Advanced actor-critic algorithms try to address these problems with different techniques.

### 1.2. Actor-Critic Architecture

The actor-critic architecture consists of two main parts:

**Actor (policy network)**

- Decides what action the agent should take.
- Learns the policy.
- Can be deterministic or stochastic.

**Critic (value network)**

- Evaluates the actor's performance.
- Estimates how valuable choosing an action is.
- This estimate is used to improve the policy.

Conceptual structure:

```
             Environment
                  |
                  v
                State
                  |
          +-------+-------+
          |               |
          v               v
        Actor           Critic
     (Policy)         (Value)
          |               |
          v               v
        Action          Q / V
          |               |
          v               |
       Environment        |
          |               |
          +-------+-------+
                  |
                  v
            Policy Update
```

In this architecture, the actor makes decisions and the critic provides feedback about the quality of the decisions.

### 1.3. Why Does the Value Function Help Policy Gradient?

In pure policy gradient, the agent can use the actual return to update the policy.

The problem is that the return may fluctuate a lot and cause high variance.

Using a value function allows us to evaluate an action's performance relative to a reference value.

This concept is related to the advantage function:

$$
A(s,a) = Q(s,a) - V(s)
$$

- $Q(s,a)$: the value of taking a specific action in a specific state.
- $V(s)$: the expected value of the state.
- $A(s,a)$: how much better or worse the action is compared with the expected performance in that state.

If the advantage is positive, the action was better than the expected average performance.

If the advantage is negative, the action performed worse.

**Main advantage:** using a value function helps reduce the variance of the policy gradient estimate and usually makes training more stable.

## 2. Basic Concepts Needed in the Chapter

Before examining the algorithms, we must distinguish several concepts from each other.

### 2.1. Discrete Action Space

The action space is discrete, meaning the agent has a limited number of actions available.

Example:

```
Actions:
- Move Left
- Move Right
- Jump
- Stay
```

These types of environments are suitable for algorithms such as DQN.

### 2.2. Continuous Action Space

The action space is continuous, meaning the action can take a wide range of numerical values.

Example in controlling a robot:

```
Actions:
- Joint 1 Angle = 25.7
- Joint 2 Angle = 48.3
- Joint 3 Angle = -12.5
```

In these environments, selecting an action from a limited set of options is not enough.

The agent must produce precise and continuous values.

Applications:

- Robotics
- Autonomous driving
- Continuous control
- Speed and movement angle control
- Physical simulation

### 2.3. Deterministic Policy

In a deterministic policy, a specific action is produced for each specific state.

$$
a = \mu(s)
$$

For example:

```
State A -> Action 0.75
State B -> Action 0.32
State C -> Action -0.45
```

If the state and policy parameters are fixed, the output is the same.

### 2.4. Stochastic Policy

In a stochastic policy, instead of producing a fixed action, a probability distribution over actions is produced.

$$
a \sim \pi(a \mid s)
$$

Example:

```
Action A: 20%
Action B: 50%
Action C: 30%
```

The agent samples from this distribution.

An important advantage of this method is the inherent possibility of exploration in the policy.

### 2.5. On-Policy and Off-Policy

**On-policy**

The agent uses data generated by its current policy for learning.

**Off-policy**

The agent can use experiences generated by previous policies or other behaviors.

Important difference:

- Off-policy allows reusing past experiences.
- On-policy usually requires newer data generated by the current policy.

| Algorithm | Learning type |
| --- | --- |
| DDPG | Off-policy |
| TD3 | Off-policy |
| SAC | Off-policy |
| PPO | On-policy |

This difference is very important in choosing the replay buffer and the training method of the algorithms.

# 3. DDPG: Deep Deterministic Policy Gradient

The first algorithm of the chapter

Approximating a deterministic policy

## 3.1. What Is DDPG?

DDPG is an actor-critic algorithm designed to solve problems with continuous action spaces.

This algorithm uses ideas from DQN, but unlike DQN, which selects actions from a discrete space, DDPG has a policy network that directly produces continuous actions.

In simple terms:

- DQN learns what Q-value to assign to each discrete action.
- DDPG learns what continuous action to produce in each state.

For example, in controlling a robot:

- DQN can choose among several predefined movements.
- DDPG can determine the precise angle of the robot's joint.

## 3.2. Why Does DDPG Use DQN Techniques?

DDPG uses several important DQN techniques to make training more stable:

**1. Experience replay**

The agent's experiences are stored in a replay buffer.

Each experience contains the following:

$$
(s, a, r, s', done)
$$

That is:

- $s$: the current state
- $a$: the action taken
- $r$: the received reward
- $s'$: the next state
- $done$: whether the episode has ended

During training, a random mini-batch is selected from the replay buffer.

Advantages:

- Reusing past experiences
- Reducing dependence between consecutive samples
- Increasing sample efficiency
- Enabling off-policy learning

**2. Target networks**

DDPG uses two sets of main networks:

- Online actor and online critic
- Target actor and target critic

The target networks are versions that change more slowly than the main networks.

Their job is to produce relatively stable targets for training the critic.

**3. Mini-batch training**

Instead of training with one experience, a set of experiences is randomly selected from the replay buffer.

This makes the training gradient less affected by one specific experience.

## 3.3. Structure of the DDPG Networks

DDPG has two main networks and two target networks.

```
                 State (s)
                     |
          +----------+----------+
          |                     |
          v                     v
      Online Actor         Online Critic
          |                     ^
          v                     |
       Action (a) --------------+
          |
          v
      Environment
          |
          v
      Experience
          |
          v
      Replay Buffer
          |
          +---------------------------+
          |                           |
          v                           v
      Target Actor               Target Critic
          |                           ^
          v                           |
     Next Action (a') ----------------+
                      |
                      v
                  Target Q
```

Note: This diagram shows the conceptual relationship among the networks. The online and target networks are separate networks, and the target actor and target critic are used in computing the target Q-value.

## 3.4. Deterministic Policy in DDPG

In DDPG, the actor learns a deterministic policy.

$$
a = \mu_\theta(s)
$$

In this relation:

- $\mu$: the policy
- $\theta$: the actor parameters
- $s$: the state
- $a$: the produced action

The actor produces a specific action for each state.

This feature is very useful for continuous control because there is no need to compute a separate Q-value for all possible actions.

## 3.5. Exploration in DDPG

An important problem with a deterministic policy is that it does not naturally create diversity in action selection.

If the agent always selects the same action for a specific state, it may miss the opportunity to discover better behaviors.

The DDPG solution is to add noise to the action.

$$
a_t = \mu_\theta(s_t) + \epsilon_t
$$

where:

- $\mu_\theta(s_t)$: the action output by the actor
- $\epsilon_t$: random noise

For example:

```
Actor Output: 0.70
Exploration Noise: 0.10

Final Action: 0.80
```

In practice, the action must be limited to the allowed range of the environment.

$$
a_t = \text{clip}(\mu_\theta(s_t) + \epsilon_t, a_{min}, a_{max})
$$

The noise can be Gaussian noise or, in the original version of DDPG, Ornstein-Uhlenbeck noise.

Important note: During evaluation, exploration noise is usually removed so that the performance of the learned policy is evaluated.

## 3.6. The Role of Q-Value in DDPG

The critic evaluates the quality of the action produced by the actor.

$$
Q_\phi(s,a)
$$

The actor's goal is to produce actions that have higher Q-values.

Therefore, the actor's optimization objective is:

$$
J(\theta) = \mathbb{E}_{s \sim D}[Q_\phi(s, \mu_\theta(s))]
$$

That is, the actor tries to produce actions that the critic evaluates as more valuable.

## 3.7. Deterministic Policy Gradient

In DDPG, the actor is updated using the gradient of the Q-function.

$$
\nabla_\theta J(\theta) = \mathbb{E} \left[ \nabla_a Q_\phi(s,a) \big|_{a=\mu_\theta(s)} \nabla_\theta \mu_\theta(s) \right]
$$

This formula is one of the most important concepts of DDPG.

Explanation of its components:

- $\nabla_a Q$: shows how a change in the action changes the Q-value.
- $\nabla_\theta \mu_\theta(s)$: shows how a change in the actor parameters changes the action.
- The product of the two gives the gradient needed to improve the actor.

As a result, the actor learns through the critic how to produce better actions.

## 3.8. Computing the Target Q in DDPG

To train the critic, the predicted Q-value must be compared with a target.

First, the target actor produces an action for the next state:

$$
a' = \mu_{\theta'}(s')
$$

Then the target critic estimates its value:

$$
y = r + \gamma(1-d) Q_{\phi'}(s', \mu_{\theta'}(s'))
$$

where:

- $r$: the reward
- $\gamma$: the discount factor
- $d$: the episode termination indicator
- $\phi'$: the target critic parameters
- $\theta'$: the target actor parameters

If the episode has ended, the future part is removed.

## 3.9. Loss Function in DDPG

The critic must bring its prediction closer to the target.

Mean squared error is used:

$$
L(\phi) = \mathbb{E} \left[ (Q_\phi(s,a) - y)^2 \right]
$$

Training steps:

1. Sample a mini-batch from the replay buffer.
2. Compute the action for the next state with the target actor.
3. Compute the target Q with the target critic.
4. Compute the predicted Q with the online critic.
5. Compute the loss.
6. Update the critic with backpropagation.
7. Update the actor with the deterministic policy gradient.
8. Slowly update the target networks.

## 3.10. Updating the Target Networks

To prevent sudden changes in the targets, a soft update is used.

$$
\theta' \leftarrow \tau\theta + (1-\tau)\theta'
$$

$$
\phi' \leftarrow \tau\phi + (1-\tau)\phi'
$$

In this relation:

- $\theta$: the online actor parameters
- $\theta'$: the target actor parameters
- $\phi$: the online critic parameters
- $\phi'$: the target critic parameters
- $\tau$: the small update coefficient

For example:

```
Online Network:  updated quickly
Target Network:  changes slowly and gradually
```

This method is also called Polyak Averaging.

## 3.11. Advantages and Disadvantages of DDPG

**Advantages:**

- Suitable for continuous action spaces
- Uses experience replay
- Uses target networks
- Allows reusing past experiences
- Directly learns the policy
- Suitable for continuous control and robotics problems

**Disadvantages:**

- Sensitivity to hyperparameters
- Greater complexity compared with DQN
- Dependence on the quality of the critic's estimate
- Possible overestimation in Q-values
- Sensitivity to noise and exploration settings
- Possible instability in training

One of the most important problems with DDPG is the Q-value estimation error. The actor may exploit the critic's errors and select actions that appear valuable only because of the incorrect estimate.

This problem was the main motivation for developing TD3.

# 4. TD3: Twin Delayed Deep Deterministic Policy Gradient

Improving DDPG

State-of-the-art improvements over DDPG

## 4.1. What Is TD3?

TD3 is an improved version of DDPG designed to reduce Q-value estimation errors and increase training stability.

The main problem with DDPG was that the critic sometimes overestimated the Q-value.

This can create a destructive cycle:

```
Critic overestimates Q-Value
            |
            v
Actor selects misleading actions
            |
            v
Critic learns from incorrect estimates
            |
            v
Q-Value overestimation increases
            |
            v
Training becomes unstable
```

TD3 tries to reduce this problem with three main techniques:

1. Clipped double Q-learning
2. Target policy smoothing
3. Delayed policy updates

## 4.2. Double Learning in TD3

In DDPG, there was one critic for estimating the Q-value.

But TD3 uses two independent critics:

$$
Q_{\phi_1}(s,a)
$$

$$
Q_{\phi_2}(s,a)
$$

These two networks try to estimate the Q-value.

The goal of using two critics is to reduce overestimation bias.

### Clipped Double Q-Learning

When computing the target, the smaller of the two estimates is selected:

$$
y = r + \gamma \min \left( Q_{\phi_1'}(s',a'), Q_{\phi_2'}(s',a') \right)
$$

Of course, this computation uses the target critics.

Example:

```
Critic 1: Q = 12
Critic 2: Q = 9

Selected Q = min(12, 9)

Target Q = 9
```

Why the smaller value?

Because selecting the larger value may cause the positive error of one critic to enter the target and be reinforced during training.

Using the minimum value reduces the risk of overestimation.

Note: This method does not guarantee that the Q-value is always accurate. It may cause slight underestimation, but it is usually useful for controlling the error.

## 4.3. Twin Critic Structure

```
             State + Action
                    |
             +------+------+
             |             |
             v             v
          Critic 1       Critic 2
             |             |
             v             v
           Q1(s,a)       Q2(s,a)
             |             |
             +------+------+
                    |
                    v
                 Minimum
                    |
                    v
                 Target Q
```

In TD3:

- There is one actor.
- There are two online critics.
- There is one target actor.
- There are two target critics.

The two critics are independent and do not necessarily share parameters.

Important note about the submitted text: Using one optimizer or combining two losses into one sum is an implementation detail and is not part of the core definition of TD3. The two critics can have separate losses and be trained in one update process.

## 4.4. Target Policy Smoothing

The second important technique of TD3 is adding noise to the action produced by the target actor.

Why?

Suppose the critic has made a very high and incorrect Q-value prediction at one point in the action space.

The actor may try to select exactly that action.

As a result, the policy becomes dependent on an incorrect estimate.

TD3 uses target policy smoothing to reduce this problem.

First, the target actor produces an action:

$$
a' = \mu_{\theta'}(s')
$$

Then Gaussian noise is added to it:

$$
\epsilon \sim \operatorname{clip}(\mathcal{N}(0,\sigma), -c, c)
$$

And the final action:

$$
\tilde{a} = \operatorname{clip}(a' + \epsilon, a_{min}, a_{max})
$$

Two clipping steps are important:

- First, the noise itself is limited.
- Then the final action is placed within the allowed range of the environment.

Example:

```
Target Actor Output: 0.70
Gaussian Noise:      0.15

Noisy Action:        0.85

Valid Action Range: -1.00 to +1.00

Final Action:        0.85
```

If the final action goes outside the allowed range, it is limited to the nearest allowed boundary.

### Difference Between the Two Types of Noise in TD3

This point is very important:

**Exploration noise**

It is added to the action during interaction with the environment so that the agent discovers new behaviors.

**Target policy smoothing noise**

It is added to the action corresponding to the target actor when computing the critic's targets so that the critic becomes more resistant to small changes in the action.

These two types of noise do not have the same purpose.

## 4.5. Delayed Policy Updates

The third TD3 technique is delaying the actor update.

In DDPG, the actor and the critic are usually updated in every training cycle.

But in TD3, the critics are updated more often than the actor.

Why?

Because the actor depends on the critic's estimate.

If the critic does not yet have an accurate estimate, updating the actor based on it can lead to incorrect decisions.

Therefore, we first let the critic learn better and then update the actor.

A common example:

```
Critic Update 1
Critic Update 2
Actor Update
Target Networks Update
```

In other words, for every two critic updates, one actor update is performed.

This value is a common setting, not a fixed rule for all environments.

Note: Delayed policy update is primarily used to increase stability and reduce the effect of critic error. It should not be considered merely a technique for balancing exploration and exploitation.

## 4.6. Why Does TD3 Use One Critic to Update the Actor?

In TD3, there are two critics, but the first critic is usually used to compute the actor gradient:

$$
\nabla_\theta J(\theta) = \mathbb{E} \left[ \nabla_a Q_{\phi_1}(s,a) \nabla_\theta \mu_\theta(s) \right]
$$

But to compute the target and train both critics, the minimum of the two target Q-values is used.

This design helps reduce computational complexity and is consistent with the main goal of TD3.

## 4.7. Advantages and Disadvantages of TD3

**Advantages:**

- Reduces overestimation bias
- Greater stability compared with DDPG
- Uses double critics
- More robust Q-value estimation with target policy smoothing
- Reduces the effect of critic error with delayed updates
- Suitable for continuous control

**Disadvantages:**

- More complex architecture than DDPG
- Requires training two critics
- Increased computational cost compared with DDPG
- Sensitivity to hyperparameters
- Still uses a deterministic policy and external noise for exploration

# 5. SAC: Soft Actor-Critic

Maximum entropy reinforcement learning

Maximizing expected return and entropy

## 5.1. What Is SAC?

SAC is an actor-critic algorithm that, in addition to increasing reward, tries to increase the entropy of the policy.

The important difference between SAC and DDPG and TD3 is in the type of policy:

- DDPG: deterministic policy
- TD3: deterministic policy
- SAC: stochastic policy

Instead of producing a fixed action, SAC learns a probability distribution over actions.

But the main feature of SAC is not only being stochastic. It is the use of the maximum entropy framework.

In this framework, the agent pursues two goals simultaneously:

1. Increasing the expected return
2. Increasing policy entropy

## 5.2. What Is Entropy?

Entropy is a concept from information theory that measures the uncertainty or spread of a probability distribution.

In reinforcement learning, entropy shows how much the policy selects diverse actions.

For a discrete policy:

$$
H(\pi) = -\sum_a \pi(a \mid s) \log \pi(a \mid s)
$$

Example:

```
Policy A:
Action 1 = 99%
Action 2 = 1%

Policy B:
Action 1 = 50%
Action 2 = 50%
```

Policy B has higher entropy because the probability of selecting actions is more diverse.

In continuous environments, entropy is computed through continuous probability distributions, usually as differential entropy.

### Why Is Entropy Important?

Suppose a robot is moving in an unknown environment.

If it always chooses one path, it may get stuck in a local optimum.

But if the policy has the possibility of selecting diverse behaviors, it has a better chance of discovering better paths.

Therefore, entropy helps exploration.

Note: High entropy alone does not guarantee useful exploration. The goal is to create controlled diversity in action selection.

## 5.3. Maximum Entropy Objective

The overall objective of SAC is:

$$
J(\pi) = \mathbb{E} \left[ \sum_{t=0}^{T} \gamma^t \left( r(s_t,a_t) + \alpha H(\pi(\cdot \mid s_t)) \right) \right]
$$

In this relation:

- $r$: the environment reward
- $H$: policy entropy
- $\alpha$: the entropy control coefficient
- $\gamma$: the discount factor

The equivalent form with log probability:

$$
J(\pi) = \mathbb{E} \left[ \sum_{t=0}^{T} \gamma^t \left( r(s_t,a_t) - \alpha \log \pi(a_t \mid s_t) \right) \right]
$$

Why is there a negative sign?

Because the log probability is more negative for low-probability actions, and therefore its negative term can create a greater reward for low-probability actions.

## 5.4. The Role of Alpha in SAC

The parameter $\alpha$ determines the importance of entropy.

```
Small Alpha
    |
    v
More focus on reward
    |
    v
More concentrated and less diverse policy
```

```
Large Alpha
    |
    v
Greater importance of entropy
    |
    v
More diverse policy and more exploration
```

Conceptually:

- Low alpha: more exploitation
- High alpha: more exploration

Of course, increasing alpha too much can prevent the agent from focusing on the main reward.

## 5.5. Soft Bellman Equation

One of the important differences between SAC and previous algorithms is incorporating entropy into the Bellman equation.

In the usual case:

$$
Q(s,a) = r + \gamma \mathbb{E}[V(s')]
$$

In SAC, the soft value function also includes entropy:

$$
V(s) = \mathbb{E}_{a \sim \pi}[Q(s,a) - \alpha \log \pi(a \mid s)]
$$

And the soft Bellman relation for Q:

$$
Q(s,a) = r + \gamma \mathbb{E}_{s',a'}[Q(s',a') - \alpha \log \pi(a' \mid s')]
$$

Here, entropy has been added to the evaluation of future value.

In this way, the agent does not only pay attention to reward. It also considers the diversity of future behavior.

## 5.6. SAC Architecture

In the common version of SAC discussed in this chapter, the structure includes the following:

- Stochastic actor
- Two online critics
- Two target critics
- Replay buffer
- Entropy coefficient

Conceptual structure:

```
                  State
                    |
                    v
                  Actor
                    |
                    v
             Action Distribution
                    |
                    v
              Sample Action
                    |
                    v
              Environment
                    |
                    v
                Experience
                    |
                    v
              Replay Buffer
                    |
              Mini-batch
                    |
          +---------+---------+
          |                   |
          v                   v
       Critic 1             Critic 2
          |                   |
          +---------+---------+
                    |
                    v
              Q Estimation
                    |
                    v
              Actor Update

          Alpha -> Entropy Control
```

Note: In the classic version of SAC described by the book, two Q-functions are used to reduce overestimation. The architectural details and the value network differ across different versions of SAC.

## 5.7. Learning the Action-Value Function

SAC uses a replay buffer for off-policy learning.

A mini-batch of past experiences is selected.

Then the action corresponding to the next state is sampled from the policy:

$$
a' \sim \pi_\theta(a' \mid s')
$$

The target Q is computed using the target critics:

$$
y = r + \gamma(1-d) \left[ \min_{i=1,2} Q_{\phi_i'}(s',a') - \alpha \log \pi_\theta(a' \mid s') \right]
$$

This target includes two parts:

- The value of the future action
- The entropy reward corresponding to the future policy

The critics then try to bring their predicted Q-values closer to this target.

The loss of each critic:

$$
L(\phi_i) = \mathbb{E} \left[ (Q_{\phi_i}(s,a) - y)^2 \right]
$$

## 5.8. Learning the Policy

The actor must produce a policy that optimizes both the expected reward and entropy.

The objective of the actor in the common version of SAC is:

$$
J_\pi(\theta) = \mathbb{E} \left[ \alpha \log \pi_\theta(a \mid s) - \min_i Q_{\phi_i}(s,a) \right]
$$

where the action is sampled from the current policy.

During optimization, this loss is usually minimized.

Therefore, the actor tries to:

- Increase the Q-value.
- Preserve or increase entropy.

## 5.9. Reparameterization Trick

In SAC, to be able to use gradient descent to train a stochastic policy, the reparameterization trick is used.

Instead of directly sampling from a distribution that depends on the network parameters, sampling is rewritten as follows:

$$
a = f_\theta(s, \epsilon)
$$

where:

$$
\epsilon \sim \mathcal{N}(0,I)
$$

For example, in a Gaussian policy:

$$
u = \mu_\theta(s) + \sigma_\theta(s) \odot \epsilon
$$

Then tanh is usually used to limit the action:

$$
a = \tanh(u)
$$

The advantage of this method is that it allows the gradient to pass from the sampling operation to the actor parameters.

This point is very important for training a stochastic policy.

## 5.10. Automatic Entropy Tuning

One of the important features of SAC is the possibility of automatically tuning alpha.

In the usual methods, we must set the value of alpha manually.

But in automatic entropy tuning, the algorithm tries to learn alpha automatically.

For this purpose, target entropy is used.

**Target entropy** is the desired amount of entropy for the policy.

This value depends on the action space.

In the common implementation of the book:

$$
H_{target} = -\dim(\mathcal{A})
$$

where:

$$
\dim(\mathcal{A})
$$

is the number of dimensions of the action space.

For example:

```
Action Space: 1 Dimension

Target Entropy = -1
```

```
Action Space: 3 Dimensions

Target Entropy = -3
```

This is a common heuristic, and it is not considered an optimal and universal value for all environments.

### Alpha Loss

In the common implementation:

$$
L(\alpha) = -\mathbb{E} \left[ \log \alpha (\log \pi(a \mid s) + H_{target}) \right]
$$

In this formula, instead of directly optimizing alpha, the log alpha value is usually learned.

The goal is to adjust the entropy coefficient to approach the target entropy.

As a result:

- If entropy is less than the desired level, the algorithm can increase alpha.
- If entropy is more than the desired level, the algorithm can decrease alpha.

In this way, the amount of exploration is adjusted automatically.

## 5.11. Gradient Clipping in SAC

The educational text refers to this command:

```
torch.nn.utils.clip_grad_norm_
```

This function is used to limit the norm of gradients.

Why is it important?

Sometimes gradients become very large and cause the network weights to change inappropriately.

This situation can lead to exploding gradients.

Gradient clipping helps keep the size of gradients within a specified range.

Advantages:

- Increased training stability
- Reduced probability of exploding gradients
- Control of network parameter changes

Note: Gradient clipping is not specific to SAC and is used in many deep learning algorithms.

## 5.12. Advantages and Disadvantages of SAC

**Advantages:**

- Stochastic policy
- Internal exploration in the policy
- Maximum entropy framework
- Uses a replay buffer
- Off-policy learning
- Automatic entropy tuning
- Suitable stability in many continuous control problems
- Suitable sample efficiency

**Disadvantages:**

- More complex architecture
- Requires tuning several networks and losses
- Relatively high computational cost
- Performance sensitivity to reward design and environment settings
- Requires proper entropy control to prevent excessive exploration

# 6. PPO: Proximal Policy Optimization

Restricting optimization steps

## 6.1. What Is PPO?

PPO is one of the important policy gradient and actor-critic algorithms whose goal is to prevent excessive changes to the policy at each training step.

The problem with usual policy gradient methods is that a large update may cause the new policy to perform much worse than the previous policy.

PPO tries to control these changes.

Main idea:

**The policy update should be large enough for learning to occur, but not so large that the agent's behavior changes drastically.**

PPO is inspired by the ideas of Trust Region Policy Optimization (TRPO) but has a simpler implementation.

## 6.2. Relationship Between PPO and A2C

PPO uses an actor-critic architecture similar to A2C.

That is, it has two main networks:

**Actor**

Learns the policy.

**Critic**

Estimates the value function.

```
             State
               |
         +-----+-----+
         |           |
         v           v
       Actor       Critic
         |           |
         v           v
       Action     Value
         |           |
         v           |
     Environment     |
         |           |
         +-----+-----+
               |
               v
          Policy Update
```

Therefore, PPO, unlike DDPG and TD3 which have deterministic policies, uses a stochastic policy in its common form.

## 6.3. Batching Experiences

One of the important topics of PPO is the use of batches of experiences.

In PPO, the agent first interacts with the environment using its current policy and collects a set of experiences.

Then the data is divided into smaller mini-batches.

Overall process:

```
Current Policy
      |
      v
Interact with Environment
      |
      v
Collect Rollout Experiences
      |
      v
Calculate Returns and Advantages
      |
      v
Create Mini-batches
      |
      v
Multiple Optimization Epochs
      |
      v
Updated Policy
```

### Important Note: PPO and the Replay Buffer

In the submitted text, it is said that PPO uses a replay buffer and reuses past experiences.

This explanation needs correction.

Standard PPO is an on-policy algorithm.

Therefore, it does not use a replay buffer in the usual sense of DQN, DDPG, and SAC.

PPO reuses the experiences from the current rollout for several training epochs.

But after updating the policy, the old data is replaced by new data for subsequent updates.

So the important difference is:

- Replay buffer: keeping experiences for reuse in the future and with different policies.
- PPO rollout buffer: temporarily keeping the experiences of the current policy for several training epochs.

These two concepts are not the same.

## 6.4. Importance Sampling in PPO

To compare the old and new policies, a probability ratio is used.

$$
r_t(\theta) = \frac{\pi_\theta(a_t \mid s_t)}{\pi_{\theta_{old}}(a_t \mid s_t)}
$$

In this relation:

- $\pi_\theta$: the new policy
- $\pi_{\theta_{old}}$: the old policy
- $a_t$: the selected action
- $s_t$: the state

This ratio shows how much the probability of selecting an action has changed in the new policy compared with the old policy.

Example:

```
Old Policy Probability = 0.20
New Policy Probability = 0.30

Ratio = 0.30 / 0.20

Ratio = 1.5
```

That is, the probability of selecting the action has increased by 50 percent compared with before.

## 6.5. Clipped Surrogate Objective

The most important feature of PPO is the use of the clipped objective.

The goal is to keep the action probability ratio within a specified range.

First, the usual policy gradient objective:

$$
L^{PG}(\theta) = \mathbb{E}[r_t(\theta) A_t]
$$

But this objective may cause large policy changes.

PPO introduces its clipped version:

$$
L^{CLIP}(\theta) = \mathbb{E} \left[ \min \left( r_t(\theta)A_t, \operatorname{clip}(r_t(\theta), 1-\epsilon, 1+\epsilon)A_t \right) \right]
$$

In this relation:

- $r_t(\theta)$: the ratio of the new and old policy probabilities
- $A_t$: the advantage
- $\epsilon$: the allowed range of changes

Usually a small value such as 0.1 or 0.2 is used for $\epsilon$. The appropriate value depends on the problem.

### The Concept of Clipping

Suppose:

$$
\epsilon = 0.2
$$

So the clipping range is:

$$
[0.8, 1.2]
$$

Example:

```
Policy Ratio = 1.50

Clipped Ratio = 1.20
```

Or:

```
Policy Ratio = 0.50

Clipped Ratio = 0.80
```

This makes the objective less sensitive to excessive policy changes.

Important note: PPO does not directly limit the ratio in an absolute way. It uses the minimum between the original objective and the clipped objective to limit excessive updates in an unfavorable direction.

## 6.6. The Role of Advantage in PPO

The advantage specifies how much better or worse the selected action was compared with the expected performance in the current state.

$$
A(s,a) = Q(s,a) - V(s)
$$

If:

$$
A(s,a) > 0
$$

it means the action was better than expected and the probability of selecting it should increase.

If:

$$
A(s,a) < 0
$$

it means the action was worse than expected and the probability of selecting it should decrease.

## 6.7. Generalized Advantage Estimation in PPO

In the chapter text, PPO uses GAE to estimate the advantage.

GAE was introduced in chapter 11.

Its goal is to reduce variance in advantage estimation and create a balance between bias and variance.

First, the TD Error:

$$
\delta_t = r_t + \gamma V(s_{t+1}) - V(s_t)
$$

Then GAE:

$$
A_t^{GAE(\gamma,\lambda)} = \sum_{l=0}^{\infty} (\gamma\lambda)^l \delta_{t+l}
$$

where:

- $\gamma$: the discount factor
- $\lambda$: the parameter controlling bias and variance
- $\delta_t$: the TD Error

By adjusting lambda, the amount of short-term and long-term information used can be controlled.

## 6.8. Value Function Clipping

In PPO, in addition to limiting policy changes, changes in the value function can also be limited.

This technique is used in some PPO implementations.

Suppose:

- $V_{old}$: the previous value function prediction
- $V_{new}$: the new prediction
- $\epsilon_v$: the allowed change range

First, the new value is clipped:

$$
V_{clip} = V_{old} + \operatorname{clip}(V_{new} - V_{old}, -\epsilon_v, \epsilon_v)
$$

Then the loss is computed.

$$
L_V = \max \left( (V_{new} - V_{target})^2, (V_{clip} - V_{target})^2 \right)
$$

The goal is for the value function not to change too much in one step.

**Correction note:** This technique does not directly clip Q-values. It limits the change in the value function prediction relative to the previous value.

Also, value clipping is an optional implementation detail and should not be considered a necessary part of all versions of PPO.

## 6.9. PPO Losses

In the actor-critic implementation, we usually have three main parts:

**1. Policy loss**

$$
L_{policy} = -L^{CLIP}(\theta)
$$

The negative sign is because in many optimizers the goal is to minimize the loss, while the main goal of PPO is to maximize the surrogate objective.

**2. Value loss**

$$
L_{value} = (V_\phi(s) - V_{target})^2
$$

This loss is used to train the critic.

**3. Entropy bonus**

$$
H(\pi)
$$

It is used to encourage exploration.

Overall combined loss:

$$
L = L_{policy} + c_1 L_{value} - c_2 H(\pi)
$$

where:

- $c_1$: the value loss coefficient
- $c_2$: the entropy bonus coefficient

## 6.10. Advantages and Disadvantages of PPO

**Advantages:**

- Suitable stability of policy updates
- Simpler implementation compared with TRPO
- Uses mini-batches
- Allows multiple training epochs on rollout data
- Uses GAE
- Suitable performance in various environments
- Suitable for discrete and continuous action spaces

**Disadvantages:**

- Being on-policy
- Requires collecting new experiences
- Lower sample efficiency compared with many off-policy methods
- Sensitivity to hyperparameter tuning
- Performance depends on batch size and the number of epochs

# 8. Important Concepts and Technical Terms of the Chapter

In this section, we summarize the concepts that have been repeated several times in the educational text.

## 8.1. Overestimation Bias

The tendency of the model to overestimate the true Q-value.

This problem can cause the selection of inappropriate actions.

Important solutions in this chapter:

- Double critic in TD3
- Using the minimum between two Q-values

## 8.2. Function Approximation Error

The error that occurs when approximating a true function with a machine learning model.

In this chapter, it refers to the errors that the neural network makes when estimating the Q-value or value function.

## 8.3. Target Networks

Networks with separate parameters that are usually updated slowly from the online networks.

Main goal:

- Producing more stable targets
- Reducing training fluctuations
- Preventing rapid changes in the targets

In DDPG and TD3, they are used for the actor and the critic. In the common version of SAC, they are used for the critic.

## 8.4. Replay Buffer

A space for storing the agent's past experiences.

```
Experience:
(s, a, r, s', done)
```

Features:

- Storing past experiences
- Random sampling
- Reducing the temporal dependence of samples
- Reusing experiences

In this chapter:

- DDPG: uses it.
- TD3: uses it.
- SAC: uses it.
- PPO: in the standard version, does not use the common replay buffer.

## 8.5. Gaussian Noise

Random noise with a normal distribution.

$$
\epsilon \sim \mathcal{N}(\mu, \sigma^2)
$$

Applications:

- Exploration in DDPG
- Exploration in TD3
- Target policy smoothing in TD3
- Sampling from a Gaussian policy in SAC

## 8.6. Clipping

Limiting the value of a variable to a specified range.

$$
\text{clip}(x, min, max) = \min(\max(x, min), max)
$$

Applications in this chapter:

- Limiting the action in DDPG and TD3
- Limiting the noise in TD3
- Limiting the policy ratio in PPO
- Limiting the change in the value function in PPO

Note: Clipping in these algorithms does not have the same purpose. The application of each one must be considered separately.

## 8.7. Delayed Updates

Updating one network at a longer interval compared with another network.

In TD3:

- The critic is updated more regularly.
- The actor is updated with a delay.
- The target networks are also usually updated together with the actor and at the same intervals.

Goal: reducing the effect of the critic's unstable estimates on the actor.

## 8.8. Entropy

A measure of the uncertainty and diversity of a probability distribution.

In SAC, it is used to create a balance between exploration and exploitation.

## 8.9. Temperature Coefficient (Alpha)

A coefficient that determines the importance of entropy in the objective of SAC.

$$
\text{Objective} = \text{Reward} + \alpha \text{Entropy}
$$

In versions with automatic entropy tuning, the value of alpha is adjusted automatically.

## 8.10. Target Entropy

The desired amount of entropy that the SAC algorithm tries to approach.

It is usually initialized based on the dimensions of the action space.

## 8.11. Reparameterization Trick

A technique for enabling gradient computation when sampling from trainable probability distributions.

Instead of directly sampling from a distribution that depends on the network parameters, an independent noise is used.

$$
a = f_\theta(s, \epsilon)
$$

This method is important in training the stochastic actor in SAC.

## 8.12. Policy Ratio

The ratio of the probability of selecting an action in the new policy to the old policy.

$$
r_t(\theta) = \frac{\pi_\theta(a_t \mid s_t)}{\pi_{old}(a_t \mid s_t)}
$$

It is one of the main concepts of PPO.

## 8.13. Clipped Surrogate Objective

An objective function in PPO that limits excessive policy changes.

Its goal is to create more conservative and stable updates.

## 8.14. Value Function Clipping

Limiting the amount of change in the value function prediction relative to the previous value.

This method is used to prevent sudden changes in the critic.

## 8.15. Gradient Clipping

Limiting the norm of gradients to prevent exploding gradients.

## 8.16. Mini-batch

A small part of the dataset used in one network training step.

Advantages:

- Lower memory usage compared with using the entire dataset
- Possibility of multiple updates
- Reduced fluctuations caused by single samples

# 11. When Should We Use Each Algorithm?

One of the most important points of the chapter is choosing the algorithm appropriate to the type of problem.

| Problem conditions | Suggested algorithm |
| --- | --- |
| Continuous action space and need for a deterministic policy | DDPG |
| Continuous action space and need for greater stability compared with DDPG | TD3 |
| Continuous action space and need for probabilistic exploration | SAC |
| Need for a general and relatively simple algorithm with controlled policy updates | PPO |
| Possibility of reusing past experiences | DDPG, TD3, or SAC |
| Need for on-policy learning | PPO |

### Practical Examples

**Robotics**

For controlling joint angles, motor speed, and robot movement:

- DDPG
- TD3
- SAC

**Game playing**

For games with discrete actions, PPO can be a suitable choice.

For continuous control of characters or vehicles in games, TD3 and SAC can also be used.

**Autonomous driving**

For continuous control of steering, acceleration, and braking, DDPG, TD3, or SAC can be used.

**Simulation environments**

In physical simulation environments such as Hopper and Walker2d, all four algorithms can be examined depending on the structure of the problem.

## 12.2. Five Important Conceptual Questions

**1. Why does DDPG use a deterministic policy?**

To directly produce continuous actions and avoid evaluating a large number of possible actions.

**2. Why does TD3 have two critics?**

To reduce overestimation bias by selecting the minimum of two Q-value estimates.

**3. Why does TD3 use delayed policy updates?**

So that the critic has the opportunity to produce more accurate estimates and the actor is not updated based on unstable estimates.

**4. Why does SAC use entropy?**

To create a balance between increasing reward and maintaining behavior diversity, and thereby strengthening exploration.

**5. Why does PPO use a clipped objective?**

To prevent excessive policy changes in one training step and increase learning stability.
