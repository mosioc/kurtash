# کتاب Grokking Deep Reinforcement Learning

کتاب **Grokking Deep Reinforcement Learning** نوشته Miguel Morales، مفاهیم یادگیری تقویتی عمیق را از مبانی ریاضی و الگوریتم‌های کلاسیک تا روش‌های پیشرفته Deep RL آموزش می‌دهد.

برای بررسی کتاب، بهتر است هر فصل را در سه بخش مطالعه کنیم:

1. **موضوعات اصلی:** فصل درباره چیست؟
2. **مهم‌ترین مفاهیم:** الگوریتم‌ها، اصطلاحات و ایده‌های کلیدی.
3. **کاربرد و ارتباط:** هر مفهوم چه مسئله‌ای را حل می‌کند و در Deep RL چه جایگاهی دارد؟

## **فهرست کامل کتاب و توضیح هر فصل**

کتاب ۱۳ فصل دارد که می‌توان آن‌ها را به چهار بخش آموزشی تقسیم کرد.

## نقشه ارتباط مفاهیم و الگوریتم‌ها

این نمودار نشان می‌دهد الگوریتم‌های مختلف Reinforcement Learning چگونه به یکدیگر مرتبط هستند و چه مسیری از مبانی RL تا الگوریتم‌های پیشرفته Deep RL طی می‌شود.

### ۱. مبانی Reinforcement Learning

- Markov Decision Process (MDP)
- Policy
- Value Functions

**ارتباط مفاهیم:**
MDP → Policy → Value Functions

### ۲. روش‌های کلاسیک Reinforcement Learning

**Value Estimation**

- Monte Carlo Methods
- Temporal Difference (TD) Learning

**Control**

- SARSA
- Q-Learning

### ۳. Deep Value-Based Reinforcement Learning

- Neural Fitted Q (NFQ)
- Deep Q-Network (DQN)
- Double DQN (DDQN)
- Dueling DQN
- Prioritized Experience Replay (PER)

**مسیر تکامل:**
NFQ → DQN → DDQN → Dueling DQN → PER

### ۴. Policy-Based و Actor-Critic Methods

- REINFORCE
- Advantage Actor-Critic (A2C)
- Asynchronous Advantage Actor-Critic (A3C)
- Deep Deterministic Policy Gradient (DDPG)
- Twin Delayed DDPG (TD3)
- Soft Actor-Critic (SAC)
- Proximal Policy Optimization (PPO)

**مسیر تکامل:**
REINFORCE → A2C / A3C → DDPG / TD3 / SAC / PPO

### ۵. موضوعات پیشرفته Reinforcement Learning

- Model-Based Reinforcement Learning
- Meta-Reinforcement Learning (Meta-RL)
- Hierarchical Reinforcement Learning
- Multi-Agent Reinforcement Learning (MARL)

**یک نکته مهم:** فصل‌های ۲ تا ۷ اهمیت زیادی دارند. اگر MDP، Bellman Equation، Value Function، TD Learning، Monte Carlo و Q-Learning به درستی درک نشوند، فهم DQN، PPO، SAC و سایر الگوریتم‌های Deep RL دشوار خواهد شد.
